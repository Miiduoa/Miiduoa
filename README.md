## 主要專案

### [Campus One](https://github.com/Miiduoa/graduation)

校園應用，整合課表、訊息、地圖與角色權限，包含行動端、Web 與共用後端。使用 Expo、Next.js、Firebase 和 TypeScript。

[案例與畫面](https://miiduoa.github.io/case-studies/campus-one/) · [程式導讀](https://github.com/Miiduoa/graduation/blob/main/docs/REVIEW_IN_2_MINUTES.md)

### [Contractscope](https://github.com/Miiduoa/contractscope)

比較兩份 OpenAPI 規格，列出變更位置、相容性判定與未涵蓋的規則。提供瀏覽器介面與 CLI，使用 TypeScript。

[開啟工具](https://miiduoa.github.io/contractscope/) · [實作說明](https://miiduoa.github.io/case-studies/contractscope/) · [規則範圍](https://github.com/Miiduoa/contractscope/blob/main/docs/rules.md)

### [Retail Ops DSS](https://github.com/Miiduoa/retail-ops-dss)

銷量預測、補貨與人力規劃原型，含門市授權與稽核紀錄。使用 Python、Streamlit、scikit-learn 和 SQLite；範例採固定種子的合成資料。

[執行方式](https://github.com/Miiduoa/retail-ops-dss#如何執行) · [介面截圖](https://github.com/Miiduoa/retail-ops-dss/tree/main/docs/screenshots)

- **[Foldpress](https://github.com/Miiduoa/foldpress)**：把 PDF 排成可雙面列印、對折裝訂的小冊子。[開啟工具](https://miiduoa.github.io/foldpress/)
